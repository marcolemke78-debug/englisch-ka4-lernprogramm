# Englisch – Klassenarbeit 4 (Unit 4: California dreams)

Interaktives Lernprogramm + druckbares Lernpaket zur Vorbereitung auf die Englisch-Klassenarbeit
(Realschule, Klasse 8, M-Niveau).

## Inhalt

**Lernprogramm (Web-App, läuft offline auf iPad/Handy):**
- Modul 1 – Wortschatz: California, Werbung/Ads, Social Media & Trends (Vokabeltrainer + Zuordnung)
- Modul 2 – Grammatik: Simple present & present progressive, Adjektiv/Adverb, Present perfect
- Modul 3 – Fit für die KA: gemischte Übungen, Hörverstehen (Browser-Vorlesefunktion), Probe-Klassenarbeit

Mit Sofort-Feedback, Selbsteinschätzung und automatischem Wiederholungsfach (Spaced Repetition).

**Lernpaket zum Ausdrucken (Ordner `pdf/`):**
- Vokabel-Lernblatt (mit Abdeck-Spalte)
- Grammatik-Merkblatt
- Übungsblatt (+ Lösungen)
- Probe-Klassenarbeit (+ Lösungen und Vorlese-Text für den Listening-Teil)

## Technik

Reines HTML/CSS/JavaScript, kein Framework, kein Build-Tool. Fortschritt wird lokal im Browser
gespeichert (localStorage). Deployment über GitHub Pages.

Inhalte nach Textbook Unit 4 (Grammatik S. 164–166, Wortschatz S. 202–205). Keine
urheberrechtlich geschützten Buchinhalte enthalten.
